# PianoVisual v1.0.31

Aggiornamento desktop per Windows del 12 ottobre 2026.

## Artisti
- All'apertura della libreria, i brani senza artista vengono completati quando il nome del brano o del file permette un'attribuzione attendibile.
- I nomi gia presenti o modificati manualmente non vengono cambiati.
- Anche i nuovi JSON importati senza campo `artist` usano questa inferenza; l'esportazione continua a includere i metadati del catalogo.
- Sulla libreria locale esaminata, 103 dei 120 artisti mancanti sono recuperabili; 17 titoli ambigui restano da verificare manualmente.

La libreria personale non e inclusa nell'installer. L'aggiornamento non modifica le tracce musicali nei JSON.
