# Release Notes v1.0.0

## Highlights
- Conversione batch MIDI -> JSON compatibile PianoVision.
- Libreria locale con gestione metadata/playlist/tag.
- Export ZIP JSON pronto per copia su Quest 3.
- Visualizer verticale con strumenti attivabili/disattivabili.

## Upgrade / migrazione
- Nessuna migrazione obbligatoria per installazioni nuove.
- Per installazioni precedenti: consigliato backup `library/db.json` e `library/json`.

## Copia su Quest 3
Copia i JSON nel percorso:
`Questo PC\Quest 3\Memoria condivisa interna\Android\data\com.ZarApps.PianoVision\files`
