# PianoVisual v1.0.34

- I MIDI importati sono conservati integri nella libreria e possono essere scaricati.
- Piano Lab comprende le riduzioni pianistiche e la nuova sezione Strumenti selezionati, con piu versioni per brano.
- Eliminando un originale, le versioni derivate rimangono disponibili e segnalano la sorgente mancante.
- I brani JSON precedenti restano accessibili separatamente; quelli senza MIDI conservato lo indicano nei dettagli.
- Il backup completo comprende i MIDI e tutte le versioni. I file personali restano esclusi da GitHub.
