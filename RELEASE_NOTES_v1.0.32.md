# PianoVisual v1.0.32

Aggiornamento desktop per Windows del 12 ottobre 2026.

## Backup completo
- Il comando `Backup completo` crea uno ZIP con tutta la libreria, compresi database, JSON dei brani, riduzioni, playlist, tag, dati di studio ed eventuali file esportati, piu tema e colori del Visualizer.
- `Ripristina backup` verifica l'archivio prima di applicarlo. La libreria precedente viene conservata accanto a quella ripristinata come copia di sicurezza.
- Lo ZIP contiene la versione dell'app nel manifesto, ma non l'installer. Reinstalla PianoVisual dalla release GitHub e poi ripristina il backup.
- L'esportazione dei soli JSON resta disponibile come comando separato.

## Note di rilascio
Nel repository sono mantenuti solo i tre file `RELEASE_NOTES` piu recenti. Il `CHANGELOG.md` conserva la cronologia estesa.
