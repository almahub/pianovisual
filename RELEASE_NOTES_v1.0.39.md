# PianoVisual v1.0.39

- Dashboard Studio aggiornata con conteggi e accesso diretto a MIDI originali, riduzioni pianistiche e versioni con strumenti selezionati.
- Le viste dei brani disponibili nascondono i record privi sia del MIDI sia del JSON, senza eliminarli automaticamente.
- Ulteriori esclusioni per evitare l'inclusione accidentale di audio e MIDI personali nel repository o nell'installer.

La release non include la libreria musicale personale. Prima di riordinare o ripristinare i dati conserva un backup completo.
