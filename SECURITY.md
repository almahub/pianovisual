# Security Policy

## Segnalare vulnerabilita
Apri una segnalazione privata al maintainer del repository oppure usa GitHub Security Advisories se disponibile.

Includi:
- descrizione problema
- impatto
- passi per riprodurre
- eventuale PoC minimale

## Ambito
Priorita a:
- path traversal
- scritture file non autorizzate
- bypass validazioni import
- injection lato API locale
